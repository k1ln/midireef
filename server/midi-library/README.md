# MIDI library

Royalty-free MIDI files for auditioning and cutting into melody blocks (Block Library → Melody → *Import from MIDI file…*, with search).

1001 files. Everything is **public domain or CC0**, with one exception:

- `clair-de-lune/Clair-de-Lune-piano-midi-de-performance.mid` is **CC BY-SA 3.0 de** — credit Bernd Krueger, piano-midi.de; derivatives must be shared under the same licence. Added on request.

Sources: **Wikimedia Commons** (files whose licence field says Public domain or CC0, checked per file through the Commons API) and the **Mutopia Project** (pieces marked Public Domain). Per-file source URL, licence, composer and style are in `manifest.json`.

Licence labels are whatever the source page stated at download time (2026-10-29); the source URL is kept so any file can be re-checked.

Your own files: drop `.mid` files into `<data dir>/midi/` — they show up in the same browser.
